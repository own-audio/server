### Recommended screenshot workflow

1. Run the app locally (`docker compose up -d`)
2. Populate with sample data (a few podcasts, an audiobook, some music tracks)
3. Use browser DevTools → "Capture screenshot" (Ctrl+Shift+P → screenshot)
4. Capture both light and dark mode if relevant
5. Resize to ~1200px wide for consistency
6. For the GIF, use [Kap](https://getkap.co/) (macOS) or [ScreenToGif](https://www.screentogif.com/) (Windows)
